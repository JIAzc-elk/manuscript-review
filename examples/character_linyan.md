# 人物卡：林砚（人物声音/关系参考）

- 身份：雨城听潮人，二十七岁，持牌三年。
- 外貌：左手腕有一道旧疤，常年穿灰布短打。
- 性格：谨慎、嘴硬、对官府不信任；不是冷酷的人，但习惯先算代价。
- 核心欲望：查清三年前妹妹林鸢的死因。
- 核心恐惧：深水。三年前他曾为救妹妹下过一次深水，之后留下潮蚀。
- 能力：听潮；水性一般；不会武。
- 知识边界：只认识码头底层的人；**不知道周家管事叫周砚山**，也不知道周家与妹妹的死有关。
- 关系：与沈鸢是临时合作，彼此不信任；沈鸢曾因听潮人害死兄长而厌恶听潮人。
- 说话方式：短句，少解释，习惯用反问挡回问题。
- 底线：不拿活人做听潮实验；但为了查妹妹的事，会隐瞒代价。
