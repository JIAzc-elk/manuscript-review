# 示例材料说明

这组文件用于演示和试跑，不属于 skill 的运行时权威。

- `chapter_17.md`：待审正文（约 1,400 字，故意包含若干可讨论的写作问题）；
- `world_rules.md`：世界/氛围参考（**不用于设定一致性审判**）；
- `character_linyan.md`：人物卡（人物声音/关系/欲望参考，**不用于一致性审判**）；
- `character_shenyuan.md`：人物卡（人物声音/关系/欲望参考，**不用于一致性审判**）；
- `sample_report.md`：演示用报告（单章局部诊断，单线程分演；不是唯一答案）。

试跑指令示例：

```text
用正文审核器审一下 examples/chapter_17.md。
素材：
- examples/world_rules.md（世界/氛围参考）
- examples/character_linyan.md（人物声音/关系参考）
- examples/character_shenyuan.md（人物声音/关系参考）
目标：好不好看、哪里不好看、怎么改更好。
```

注意：
- 示例正文中的人物、地名、组织均为虚构；示例报告不应被视为唯一正确答案。
- 单章只能做局部诊断；正式使用建议至少给一个序列（3–8 章）或一幕，并附前情/幕纲。
