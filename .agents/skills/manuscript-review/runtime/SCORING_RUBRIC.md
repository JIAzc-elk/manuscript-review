# 评分规则

> 分数是**诊断工具**，不是文学价值的终审判决。所有分数必须能回到 findings 与证据；不能先有分数再找理由。

## 1. 评分维度与权重

| 维度 | 代码 | 权重 | 评什么 |
|---|---|---|---|
| 人物与矛盾 | CH | 25% | 人物矛盾、压力选择、动机、能动性、可信度、知识边界、关系连续、人物声音、人物弧 |
| 故事设计与结构 | ST | 25% | 激励事件、求索/脊椎、鸿沟、幕/序列逆转、不归点、危机/高潮、章节功能、因果、升级、赌注、信息架构、承诺/兑现、节奏、结尾 |
| 场景执行与对白 | SD | 25% | 场景价值转折、场景目标、beat、对白行动、潜台词、信息交付、调度、文字执行 |
| 设定与世界逻辑 | WD | 15% | 规则一致、世界状态、制度行为、资源权力、信息生态、设定呈现 |
| 语言与阅读体验 | PR | 10% | 可读性、语言精度、重复冗余、文风一致、AI 味/模板化 |

默认权重适用于大多数类型。用户明确类型时可调整，但必须在报告中写明调整理由与前后权重（例如设定流科幻把 WD 提到 20%，PR 降到 5%）。**不得为了抬高/压低总分临时改权重。**

某维度确实无法评估时（极少见），把该维度权重按比例分给其余维度，并标注“该维度未评”。不能给“默认 7 分”。

## 2. 单维度 1–10 分锚点

| 分数 | 含义 | 典型表现 |
|---|---|---|
| 9.5–10 | 范本级 | 几乎无可实质修改；细节打磨即可；可作为同类写作参考 |
| 9.0–9.4 | 优秀 | 完成度高，偶有 P2；没有影响阅读的 P1 |
| 8.0–8.9 | 良好 | 成熟，有少量 P1 或若干 P2；修改后更稳 |
| 7.0–7.9 | 合格 | 基础成立，但有明显可改进项；P1 开始影响体验 |
| 6.0–6.9 | 及格线 | 存在影响阅读的 P1；结构/人物/场景之一有明显薄弱 |
| 5.0–5.9 | 勉强成立 | 有明显失效，需要较大修改；读者可能中途失去兴趣 |
| 4.0–4.9 | 较大问题 | 核心场景/因果/人物之一不成立，需要重写部分内容 |
| 3.0–3.9 | 严重失效 | 章节功能或核心机制不成立，建议重写 |
| 1.0–2.9 | 不可读/崩坏 | 大量硬伤、逻辑断裂、语言障碍 |

允许 0.5 分刻度。不要给 7.3 这种伪精确到 0.1 的分数，除非有明确锚点支撑；默认 0.5 刻度。

### 2.1 维度内部看什么

**CH 人物与矛盾**
- 人物内部/个人/超个人冲突是什么？有没有生产性矛盾？
- 压力下的选择是否揭示人物真相？人物是否可替换？
- 动机链是否闭合？Why Now 是否成立？
- 有无强潜在 OOC？变化是否有桥？人物弧是否可信？
- 知识边界是否守住？关系是否连续、有方向性？
- 人物声音是否可区分？

**ST 故事设计与结构**
- 激励事件是否打破平衡、迫使主角选择？时机是否合适？
- 求索/脊椎是否清楚？主角想要什么（意识/潜在欲望）？
- 鸿沟是否驱动新行动？是否升级？
- 幕/序列逆转是否重大、不可逆、有铺垫？
- 不归点何时发生？代价是否可见？
- 危机/高潮是否由主角选择？结局是否给余波/新平衡？
- 章节功能是否清楚并完成？因果、赌注、信息架构、承诺/兑现、节奏是否有效？

**SD 场景执行与对白**
- 每场的价值电荷是否变化？有没有场景价值转折？
- 每场是否有目标、障碍、转折、结果（或明确替代功能）？
- 对白是否作为行动？潜台词是否有效？
- 信息交付是否自然？有无解释倾倒/As-you-know？
- 调度、视角、感官是否清楚？
- 文字执行是否服务场景？

**WD 设定与世界逻辑**
- 规则的成本/限制/副作用是否被遵守？
- 世界状态、时间线、资源是否连续？
- 势力/制度是否按自身逻辑行动？
- 信息传播是否合理？设定是否自然露出？
- 与 A 级素材是否冲突？

**PR 语言与阅读体验**
- 是否清楚、顺畅、适合目标平台？
- 语言是否精确、有画面感、不空洞？
- 重复/冗余是否过多？
- 文风是否稳定？有无明显 AI 味/模板化？

## 3. 总分计算

```text
原始总分 = CH×0.25 + ST×0.25 + SD×0.25 + WD×0.15 + PR×0.10
最终总分 = min(原始总分, 所有适用的 P0 上限)
```

四舍五入到 0.5 分。报告里同时给原始分与最终分（若被上限压低），让用户看到差距来自哪里。

### 3.1 P0 上限（只压不抬）

| 条件 | 总分上限 |
|---|---|
| 1 条未解决的 P0 | 6.5 |
| 2 条未解决的 P0 | 5.8 |
| 3 条及以上未解决的 P0 | 5.0 |
| P0 涉及章节功能/核心因果（删掉这章后文不成立、关键转折无因果） | 5.0（无论条数） |
| 与 A 级设定明确冲突且未解决 | 6.0 |
| 主角/核心人物强潜在 OOC 且无因果桥 | 6.0 |

多条上限同时适用时取**最低**值。P0 被确认解决/撤回后，上限解除；报告中要写清“若修掉 X，分数可回到 Y 附近”。

### 3.2 故事设计分（Craft Index）

五维总分回答“整体质量”，Craft Index 回答“故事设计是否好看”。**两者并列，不互相替代。**

Craft Scorecard 共 10 项，每项 1–5，详见 `.agents/skills/manuscript-review/runtime/STORY_CRAFT_LENS.md` §11：

1. 激励事件
2. 求索 / 故事脊椎
3. 鸿沟
4. 场景价值转折
5. 序列 / 幕逆转
6. 不归点
7. 危机 / 高潮 / 结局
8. 人物矛盾
9. 人物弧
10. 类型契约 / 读者体验

```text
故事设计分 = 10 项平均 × 2（1–10，0.5 刻度）
```

报告必须同时给：

- **总分**（五维加权，含 P0 上限）；
- **故事设计分**（Craft Index）；
- **两者差距的解释**：

| 情况 | 解释 |
|---|---|
| Craft Index 明显低于总分 | 逻辑/文字尚可，但故事设计是短板；优先修激励事件/求索/鸿沟/逆转/不归点 |
| Craft Index 明显高于总分 | 故事有想法，但执行/逻辑/文字拖后腿；优先修规则、场景、语言 |
| 两者接近 | 发展均衡；按 P0/P1 修即可 |

**不把 Craft Index 再加权进总分**，避免与 ST/CH/SD 重复计分；它是“是否好看”的诊断透镜。若维度分与子分差距大，报告要解释“为什么整体判断高于/低于某一项”。

### 3.3 计算示例

```text
CH 7.5 × 0.25 = 1.875
ST 8.0 × 0.25 = 2.000
SD 7.0 × 0.25 = 1.750
WD 8.5 × 0.15 = 1.275
PR 7.5 × 0.10 = 0.750
原始总分 = 7.65 → 7.5（0.5 刻度）
存在 1 条 P0（人物知识泄漏）→ 上限 6.5
最终总分 = 6.5
报告写：原始 7.5，因 P0 上限压至 6.5；修掉知识泄漏后可回到 7.5 左右。
```

## 4. 等级与发布建议

| 总分 | 等级 | 含义 |
|---|---|---|
| 9.0–10 | S · 范本 | 可直接作为同类参考 |
| 8.0–8.9 | A · 优秀 | 小修即可 |
| 7.0–7.9 | B · 良好 | 中修；有明显提升空间 |
| 6.0–6.9 | C · 合格待修 | 大修或至少修掉 P0/P1 |
| 5.0–5.9 | D · 较大问题 | 需要重写部分场景/章节 |
| < 5.0 | E · 建议重写 | 核心机制不成立 |

**发布建议与分数分开写。** 分数高不等于平台一定接受；分数低也不等于不能发。发布建议要结合：

- 用户目标（练笔/存稿/签约/发布/比赛）；
- 类型与平台契约；
- 修改成本与时间；
- 是否存在“读者会立刻弃书”的硬伤。

发布建议四档：`可直接发` / `小修后发` / `大修后发` / `建议重写后再发`。给出理由，不只给结论。

## 5. 置信度

| 置信度 | 条件 | 报告写法 |
|---|---|---|
| 高 | 正文完整；A 级素材充分；多角色独立结论大体一致；关键争议已核证 | 给点分 |
| 中 | 素材部分缺失；有未决分歧；文本存在多种合理解读；部分角色缺失 | 给点分 + “±0.5” |
| 低 | 关键材料缺失；单线程分演；大量未决；章节明显是残缺片段 | 给区间（如 6.0–7.0），标“暂评” |

置信度低时，不得用精确分数制造权威感。报告要写明“哪些结论会随材料补充而改变”。

## 6. 评分纪律

1. **先 findings，后分数。** 不能先定“这章 8 分”再找理由。
2. **一条问题只扣一个维度。** 跨域问题按根因归属；其他维度只记影响，不重复扣分。
3. **P0 是上限，不是额外扣分项。** 维度分反映该维度整体表现（可以因为同一个问题偏低），P0 上限是额外的总分保护；报告中要同时给原始加权分与上限后的总分，避免读者误以为被双重惩罚。
4. **不因角色数量投票。** 四个角色都说 7 分，不代表就是 7 分；看锚点。
5. **不因个人口味压分。** 不喜欢类型、不喜欢文风、不喜欢人物，都不是低分理由；必须说清“对目标读者的影响”。
6. **不因“努力/潜力”加分。** 评的是这一章，不是作者的未来。
7. **不因“商业性”直接加分。** 爽点、钩子可以加分，但要说明它们服务了什么读者体验。
8. **不评无法评的东西。** 文学史地位、市场销量、作者人品、版权风险，不在评分范围。
9. **分数要可复算。** 报告附计算表；秘书核对算术；用户能看懂为什么是这个分。
10. **修改后复评。** 如果用户拿改稿再来，重新跑流程，不沿用旧分；可以对照旧报告说明变化。

## 7. 评分讨论流程

1. Round 2 结束后，CH/ST/SD/WD 四个角色各给自己的维度一个初评分 + **Craft 子分** + 一句理由 + 置信度。子分范围见 `STORY_CRAFT_LENS.md`：
   - ST：激励事件、求索、鸿沟、幕/序列逆转、不归点、危机/高潮、章节功能；
   - CH：人物矛盾、人物弧、关系/知识边界；
   - SD：场景价值转折、对白行动/潜台词、信息交付、调度/文字。
2. 主持对照锚点校准，处理手松/手紧、重复扣分、跨域归属；**维度分与 Craft 子分差距大时，必须解释为什么**。
3. PR 由 `scene_dialogue` 给初评，主持复核（语言维度不单独派角色）。
4. 魔鬼检查：有没有严重度虚高/漏掉 P0/分数与证据不匹配；**Craft 子分有没有虚高（把“有元素”当“做得好”）或虚低（把类型选择当缺陷）**。
5. 秘书核算加权、P0 上限与 Craft Index（10 项平均 × 2）。
6. 主持定稿，对总分与故事设计分负最终责任。

## 8. 报告中的评分呈现

最低要求：

```text
总分：6.5 / 10（C · 合格待修）｜置信度：中（±0.5）
原始加权分：7.5｜因 1 条 P0 压至 6.5

人物与关系   7.5  动机链基本成立；主角对配角的信任缺少过渡
结构与节奏   8.0  章节功能清楚，升级靠约束而非场面，结尾钩子有效
场景执行     7.0  两场对话信息密度过高；第三场转折略快
设定与世界   8.5  规则一致；势力反应合理
语言与阅读   7.5  整体顺畅；中段有重复解释和少量套话
```

分数后面必须有一句“为什么”，不能只有数字。

### 8.1 故事设计评分呈现

```text
故事设计分（Craft Index）：5.8 / 10

激励事件      3.0  夺基事件成立，但主角只是被动承受
求索          2.0  只有“活下去/杀回去”，缺具体目标
鸿沟          2.5  有意外，但角色调整不够
场景价值转折  2.5  多数场景靠信息/情绪变化，价值翻转少
幕/序列逆转   3.5  夺基与自爆是有效逆转，但中段平
不归点        4.0  自爆切断退路，代价可见
危机/高潮     3.5  高潮是选择，但靠燃烧资源而非两难
人物矛盾      2.5  主角只有“杀”，反派有账本但缺对手级压力
人物弧        2.0  本章几乎无变化
类型契约      3.5  男频开篇钩子强，套路执行在线
```

- 故事设计分与总分并列；不要用一个数字替代另一个。
- 如果 Craft Index 低于总分，报告要明确指出“逻辑/文字 > 故事设计”，并优先给 craft 修改方案。
- 如果 Craft Index 高于总分，报告要明确指出“故事有想法，但执行拖后腿”，并优先修规则/场景/语言。
