# 评分规则（写作技巧优先）

> 分数是**诊断工具**，不是文学价值的终审判决。所有分数必须能回到 findings 与正文证据；不能先有分数再找理由。
>
> **本 skill 只评写作技巧，不评逻辑/设定一致性。**

## 1. 评分维度与权重

| 维度 | 代码 | 权重 | 评什么 |
|---|---|---|---|
| 场景与戏剧效果 | SC | 25% | 场景目标/阻力/转折、beat、价值翻转、入口/出口、戏剧张力 |
| 对白与人物声音 | DL | 20% | 对白行动、潜台词、人物声音、信息交付、对话节奏 |
| 描写与文字 | PR | 20% | 感官/POV、具体性、比喻、动词、套话/AI 味、文风 |
| 节奏与可读性 | PA | 15% | 句长/段落、压缩/展开、场景/章节节奏、章末钩子 |
| 人物与情感 | CH | 10% | 欲望、矛盾、选择、魅力、关系、情感落点、人物弧 |
| 幕/序列效果 | ST | 10% | 幕功能、激励、渐进复杂化、中点、危机/高潮、收束、章功能分布 |

**没有“设定/世界逻辑”维度。** 本 skill 不做设定一致性、时间线、知识边界分析。

默认权重适用于大多数类型。用户明确类型时可调整，但必须在报告中写明理由与前后权重。**不得为了抬高/压低总分临时改权重。**

**单章模式（`chapter_local`）**：幕/序列效果 = `N/A`，其 10% 按比例分摊给其余五维：

```text
SC 27.8% + DL 22.2% + PR 22.2% + PA 16.7% + CH 11.1% = 100%
```

总分写“**局部诊断分**”，不写“幕级总分”。Craft Scorecard 的“幕/序列升级/逆转”标 `N/A`，Craft Index 只平均其余 9 项（仍 ×2，但分母改为 9）。

## 2. 单维度 1–10 分锚点

| 分数 | 含义 | 典型表现 |
|---|---|---|
| 9.5–10 | 范本级 | 几乎无可实质修改；细节打磨即可；可作为同类写作参考 |
| 9.0–9.4 | 优秀 | 完成度高，偶有 P2；没有影响阅读的 P1 |
| 8.0–8.9 | 良好 | 成熟，有少量 P1 或若干 P2；修改后更稳 |
| 7.0–7.9 | 合格 | 基础成立，但有明显可改进项；P1 开始影响体验 |
| 6.0–6.9 | 及格线 | 存在影响阅读的 P1；场景/对白/描写之一有明显薄弱 |
| 5.0–5.9 | 勉强成立 | 有明显失效，需要较大修改；读者可能中途失去兴趣 |
| 4.0–4.9 | 较大问题 | 核心场景/人物/节奏之一不成立，需要重写部分内容 |
| 3.0–3.9 | 严重失效 | 章节/序列功能或核心体验不成立，建议重写 |
| 1.0–2.9 | 不可读/崩坏 | 大量硬伤、语言障碍、读者无法进入 |

允许 0.5 分刻度。不要给 7.3 这种伪精确到 0.1 的分数，除非有明确锚点支撑；默认 0.5 刻度。

### 2.1 维度内部看什么

**SC 场景与戏剧效果**
- 每场谁想要什么？阻力是什么？结束时什么变了？
- 入口是否够快？beat 是否有推进？结尾是否落在决定/转折？
- 场景是否在“发生”事情，而不是只交流信息？
- 有没有价值翻转/戏剧张力？

**DL 对白与人物声音**
- 每句对白在做什么（请求/拒绝/试探/威胁/回避/承认）？
- 潜台词是否有效？信息交付是否自然？
- 人物声音是否可区分（词汇/句长/遮掩方式）？
- 对话节奏是否服务场景？

**PR 描写与文字**
- POV/感官是否清楚？描写是否具体、节制、服务场景？
- 比喻是否准确、新鲜？有没有套话/AI 味/同构比喻？
- 动词是否具体？有没有用形容词代替动作？
- 文风是否稳定、贴合作者？

**PA 节奏与可读性**
- 句长/段落是否有变化？适合目标平台吗？
- 压缩/展开是否合理？哪里该快、哪里该慢？
- 有没有连续解释/内心独白打断动作？
- 章末是否给出具体期待？

**CH 人物与情感**
- 人物想要什么？矛盾是什么？选择是否揭示人物？
- 人物是否有魅力/记忆点？关系是否有张力？
- 情感是否由动作/选择/代价支撑，而不是旁白宣布？
- 人物弧/关系变化是否可信？

**ST 幕/序列效果**
- 这一幕/序列在卷/全书里做什么？功能完成了吗？
- 有没有幕级逆转/中点？冲突是否渐进复杂化？
- 高潮是否由主角选择造成？收束是否留下不可逆变化/新问题？
- 章功能分布是否合理？有没有空转章/重复章？

## 3. 总分计算

```text
原始总分 = SC×0.25 + DL×0.20 + PR×0.20 + PA×0.15 + CH×0.10 + ST×0.10
最终总分 = min(原始总分, 所有适用的 P0 上限)
```

四舍五入到 0.5 分。报告里同时给原始分与最终分（若被上限压低），让用户看到差距来自哪里。

### 3.1 P0 上限（只压不抬，按“写作技巧阻断”定义）

| 条件 | 总分上限 |
|---|---|
| 1 条未解决的 P0 | 6.5 |
| 2 条未解决的 P0 | 5.8 |
| 3 条及以上未解决的 P0 | 5.0 |
| P0 涉及整章/整幕无法阅读/无法进入（场景无功能、叙述不可读、主角完全无欲望/无行动、幕级逆转缺失） | 5.0（无论条数） |
| 核心场景/高潮完全失效，读者没有继续读的理由 | 5.0 |

**P0 是写作技巧阻断，不是“设定冲突”。** 本 skill 不评设定/逻辑一致性。

多条上限同时适用时取**最低**值。P0 被确认解决/撤回后，上限解除；报告中要写清“若修掉 X，分数可回到 Y 附近”。

### 3.2 写作技巧分（Craft Index）

五/六维总分回答“整体质量”，Craft Index 回答“写作技巧是否好看”。**两者并列，不互相替代。**

Craft Scorecard 共 10 项，每项 1–5，见 `.agents/skills/manuscript-review/runtime/WRITING_CRAFT_LENS.md` §12：

1. 场景目标/转折
2. 对白行动/潜台词
3. 人物声音
4. 描写/感官/POV
5. 节奏/句法
6. 情绪落点
7. 人物欲望/矛盾
8. 人物弧/关系
9. 幕/序列升级/逆转
10. 类型契约/读者体验

```text
写作技巧分 = 10 项平均 × 2（1–10，0.5 刻度）
```

报告必须同时给：

- **总分**（六维加权，含 P0 上限）；
- **写作技巧分**（Craft Index）；
- **两者差距的解释**：

| 情况 | 解释 |
|---|---|
| Craft Index 明显低于总分 | 整体尚可，但写作技巧/文字执行是短板；优先修场景/对白/描写/节奏 |
| Craft Index 明显高于总分 | 文字/场景有亮点，但幕结构/人物/类型契约拖后腿 |
| 两者接近 | 发展均衡；按 P0/P1 修即可 |

**不把 Craft Index 再加权进总分**，避免与 SC/DL/PR 重复计分；它是“好不好看”的诊断透镜。

### 3.3 计算示例

```text
SC 7.5 × 0.25 = 1.875
DL 7.0 × 0.20 = 1.400
PR 7.0 × 0.20 = 1.400
PA 7.5 × 0.15 = 1.125
CH 7.5 × 0.10 = 0.750
ST 8.0 × 0.10 = 0.800
原始总分 = 7.35 → 7.5（0.5 刻度）
存在 1 条 P0（核心场景失效）→ 上限 6.5
最终总分 = 6.5
报告写：原始 7.5，因 P0 上限压至 6.5；修掉核心场景后可回到 7.5 左右。
```

## 4. 等级与发布建议

| 总分 | 等级 | 含义 |
|---|---|---|
| 9.0–10 | S · 范本 | 可直接作为同类参考 |
| 8.0–8.9 | A · 优秀 | 小修即可 |
| 7.0–7.9 | B · 良好 | 中修；有明显提升空间 |
| 6.0–6.9 | C · 合格待修 | 大修或至少修掉 P0/P1 |
| 5.0–5.9 | D · 较大问题 | 需要重写部分场景/章节 |
| < 5.0 | E · 建议重写 | 核心体验不成立 |

**发布建议与分数分开写。** 分数高不等于平台一定接受；分数低也不等于不能发。发布建议要结合：

- 用户目标（练笔/存稿/签约/发布/比赛）；
- 类型与平台契约；
- 修改成本与时间；
- 是否存在“读者会立刻弃书”的体验问题。

发布建议四档：`可直接发` / `小修后发` / `大修后发` / `建议重写后再发`。给出理由，不只给结论。

## 5. 置信度

| 置信度 | 条件 | 报告写法 |
|---|---|---|
| 高 | 单位完整；前情/幕纲/人物卡/文风参考充分；多角色独立结论大体一致；关键争议已核证 | 给点分 |
| 中 | 上下文部分缺失；有未决分歧；单位是序列而非整幕；部分角色缺失 | 给点分 + “±0.5” |
| 低 | 只有单章/片段；关键材料缺失；单线程分演；大量未决 | 给区间（如 6.0–7.0），标“局部/暂评” |

置信度低时，不得用精确分数制造权威感。报告要写明“哪些结论会随材料补充而改变”。

## 6. 评分纪律

1. **先 findings，后分数。** 不能先定“这章 8 分”再找理由。
2. **一条问题只扣一个维度。** 跨域问题按根因归属；其他维度只记影响，不重复扣分。
3. **P0 是上限，不是额外扣分项。** 维度分反映该维度整体表现，P0 上限是额外的总分保护；报告中要同时给原始加权分与上限后的总分。
4. **不因角色数量投票。** 多个角色都说 7 分，不代表就是 7 分；看锚点。
5. **不因个人口味压分。** 不喜欢类型/文风/人物，都不是低分理由；必须说清“对目标读者的影响”。
6. **不因“努力/潜力”加分。** 评的是这一单位，不是作者的未来。
7. **不因“商业性”直接加分。** 爽点/钩子可以加分，但要说明它们服务了什么读者体验。
8. **不评无法评的东西。** 文学史地位、市场销量、作者人品、版权风险，不在评分范围。
10. **分数要可复算。** 报告附计算表；秘书核对算术；用户能看懂为什么是这个分。
11. **修改后复评。** 如果用户拿改稿再来，重新跑流程，不沿用旧分；可以对照旧报告说明变化。

## 7. 评分讨论流程

1. Round 2 结束后，SC/DL/PR/PA/CH/ST 六个维度各给 1–10 初评分 + **写作技巧子分** + 一句理由 + 置信度：
   - SC：场景目标/转折、价值翻转、入口/出口；
   - DL：对白行动/潜台词、人物声音、信息交付；
   - PR：描写/感官/POV、具体性、比喻、套话；
   - PA：句长/段落、压缩/展开、章末钩子；
   - CH：欲望/矛盾/选择/魅力/关系/弧；
   - ST：幕功能、逆转/中点、高潮/收束、章功能分布。
2. 主持对照锚点校准，处理手松/手紧、跨维度重复扣分；维度分与子分差距大时，必须解释为什么。
3. 魔鬼检查：有没有把“我不喜欢”当低分、把类型选择当缺陷、把“有元素”当“做得好”；写作技巧子分是否虚高/虚低。
4. 秘书核算加权、P0 上限与 Craft Index（10 项平均 × 2）。
5. 主持定稿，对总分与写作技巧分负最终责任。

## 8. 报告中的评分呈现

最低要求：

```text
总分：7.5 / 10（B · 良好）｜置信度：中（±0.5）
写作技巧分（Craft Index）：7.8 / 10
原始加权分：7.5｜无 P0 上限

场景与戏剧   7.5  两场有转折；第三场入口慢
对白与声音   7.5  主角短句有效；反派台词偏解释
描写与文字   7.0  雨/灯的意象好；中段比喻重复
节奏与可读   7.5  手机阅读顺畅；战斗中间有一段说明
人物与情感   8.0  欲望清楚；关系张力在线
幕/序列效果  7.5  章功能清楚；中点略平
```

分数后面必须有一句“为什么”，不能只有数字。

### 8.1 写作技巧评分呈现

```text
写作技巧分（Craft Index）：7.8 / 10

场景目标/转折   4.0  每场有目标；第二场转折靠台词
对白行动/潜台词 4.0  主角对白在做事；反派偏解释
人物声音       4.5  三人可区分；配角偏薄
描写/感官/POV  3.5  雨/灯意象好；比喻重复
节奏/句法       4.0  整体顺；战斗中间有说明停顿
情绪落点       4.0  章末钩子有效；中段情绪平
人物欲望/矛盾   4.5  主角欲望清楚；反派有账本
人物弧/关系     3.5  关系有变化；弧光刚起步
幕/序列升级/逆转 4.0  章末威胁升级；中点略平
类型契约/读者体验 4.5  男频开篇钩子强；套路执行在线
```

- 写作技巧分与总分并列；不要用一个数字替代另一个。
- 如果 Craft Index 低于总分，报告要明确指出“整体尚可，但写作技巧/文字执行是短板”。
- 如果 Craft Index 高于总分，报告要明确指出“文字/场景有亮点，但幕结构/人物/类型契约拖后腿”。
