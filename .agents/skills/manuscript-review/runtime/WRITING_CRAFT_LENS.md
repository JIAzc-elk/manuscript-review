# 写作技巧透镜（Craft-First）

> 目的：回答**“好不好看、哪里不好看、怎么写更好”**。
>
> 本 skill 只评写作技巧，不做逻辑/设定一致性审查。
>
> 理论是透镜，不是法律；类型契约优先；不要用评审团的风格覆盖作者的声音。

## 0. 原则

1. **先看读者体验，再看技法**：读者会不会想继续读？哪里出戏？哪里被打动？
2. **先看功能，再看好坏**：这一场/这一章/这一幕要做什么？做到了吗？
3. **给技法，不给判决**：不说“人物不立体”，说“他的欲望没有被一个具体选择暴露出来；可以试试把解释改成动作”。
4. **给更好的写法，不代写**：最多 1–2 句示例，标注“示例，不是代写”。
5. **保留作者声音**：不要把所有句子改成同一种“干净利落”的评审团文风。
6. **类型不是缺陷**：爽、慢、留白、群像、第一人称碎碎念，都可能是有效选择；先问类型契约。
7. **只评写作技巧**：不审设定冲突、时间线、知识边界；把力气放在“好不好看、怎么写更好”。

## 1. 场景 craft

**问**：

- 这一场谁想要什么？阻力是什么？结束时什么变了？
- 入口是否够快？读者是否知道“我们在哪、为什么在这”？
- beat 是否有推进：试探→拒绝→威胁→让步→反转？
- 场景是否在“发生”事情，还是只在“交流信息”？
- 结尾是否落在决定/转折/钩子上，而不是拖尾？

**常见病症**：

- 场景没有目标/阻力/转折，读完像原地踏步；
- 入口太慢：先写环境/日常，冲突迟迟不来；
- 中段停在同一个情绪/信息上；
- 结尾拖尾：该断的地方不断，把余味解释掉。

**更好的写法**：

- 从**异常/冲突/决定**开始，环境细节在动作中带出；
- 让每场至少有一个**价值翻转**（安全→危险、信任→怀疑、希望→失望）；
- 用**物件/动作**承载情绪，不要让旁白总结；
- 在**决定点**结束，不要在下一次解释后结束。

## 2. 对白 craft

**问**：

- 每句对白在做什么：请求、拒绝、试探、威胁、安抚、回避、挑衅、承认、转移？
- 有没有“说了很多但局势没变”？
- 潜台词是否有效：人物说的和要的是否有落差？
- 人物声音是否可区分：词汇、句长、逻辑、遮掩方式？
- 信息交付是否自然：有没有 As-you-know、解释倾倒、重复交付？

**常见病症**：

- 对白只是作者借人物之口解释设定；
- 所有人都说同一种“聪明/俏皮/文青”语言；
- 潜台词过度隐晦，读者看不懂；或过度解释，没有潜台词；
- 对话标签过多/过花，动作缺失；
- 人物回答得太完整、太正确，像访谈。

**更好的写法**：

- 让对白**做事**：每句改变关系/信息/权力/下一步；
- 用**答非所问、打断、沉默、重复**制造潜台词；
- 给每个人一个**遮掩方式**：有人用玩笑，有人用命令，有人用沉默；
- 把解释拆进**冲突/动作/物件**，不要一口气讲完；
- 对话标签用“说”+动作，少用“冷冷地/淡淡地/意味深长地”。

## 3. 描写 craft

**问**：

- 这段描写是谁在看？他此刻在意什么？他的情绪如何过滤环境？
- 感官细节是否具体、节制、服务场景？
- 比喻是否准确、新鲜、服务情绪？有没有混合比喻/过度比喻？
- 是否在用形容词代替动作？动词是否具体？
- 有没有套话、AI 味、同构比喻、四字成语堆砌？

**常见病症**：

- 全知镜头：环境描写没有 POV，谁都能看；
- 形容词堆砌：“美丽、壮观、恐怖、震撼”但不具体；
- 比喻过密：每句都在比喻，读者疲劳；
- 套话：“空气仿佛凝固”“心中五味杂陈”“不易察觉地”；
- 描写不服务场景：为了画面感而画面感，打断冲突。

**更好的写法**：

- **一个准确比喻 > 三个漂亮比喻**；比喻要服务人物此刻的情绪；
- 用**具体名词/动词**代替形容词：不写“很害怕”，写“他把刀握反了”；
- 用**POV 过滤**：他此刻是逃命，看到的是出口/追兵/脚下的泥，不是全景建筑；
- 用**物件**承载情绪：灵牌、断香、旧伤、雨声；
- 描写**只留推动场景/情绪/信息**的部分，其余删。

## 4. 节奏 craft

**问**：

- 句子长短是否有变化？紧张场景是否用短句/断句？
- 段落是否适合目标平台（手机阅读/连载）？
- 有没有连续大段说明/内心独白？
- 场景/章节的压缩/展开是否合理？哪里该快、哪里该慢？
- 章末是否给出具体期待？

**常见病症**：

- 全程同一节奏：要么一直短句，要么一直长句；
- 连续解释/回忆打断动作；
- 该快的地方慢（战斗中间讲设定），该慢的地方快（情感高潮一笔带过）；
- 章末平收，没有具体问题/决定/威胁。

**更好的写法**：

- 紧张时**短句+具体动作**；抒情时放慢，但不要空转；
- 把解释**移到动作之后**，或拆成两句；
- 用**场景断点/时间跳跃**压缩无关过程；
- 章末留**一个具体问题/决定/威胁**，不要用“欲知后事”式空钩。

## 5. POV / 叙述距离

**问**：

- 这一场/这一章的 POV 是谁？有没有无标记跳视角？
- 叙述者知道/不知道什么？有没有泄露 POV 不应知道的信息？
- 叙述距离是否稳定？有没有突然从贴身限知跳到全知解释？
- 读者是否通过 POV 的感官/判断进入场景？

**常见病症**：

- head-hopping：一段里跳进三个人的脑子；
- 全知解释打断贴身情绪；
- POV 角色看到的细节不符合他的知识/情绪；
- 叙述距离忽远忽近，读者晕。

**更好的写法**：

- 每场先定**一个 POV**；要换 POV，用场景/章节断开；
- 用 POV 的**注意力**过滤环境：他怕什么，就先看到什么；
- 把全知解释改成 POV 的**猜测/误判**，让人物性格参与叙事；
- 高潮处把镜头拉近，不要拉远解释。

## 6. 情绪 / 读者体验

**问**：

- 这一场/这一章想让读者感受什么？期待、紧张、愤怒、爽、心疼、好奇？
- 情绪曲线是否有起有落？有没有连续的平/连续的吼？
- 情绪是否被**动作/选择/代价**支撑，而不是被旁白宣布？
- 读者是否在乎？为什么在乎？

**常见病症**：

- 情绪靠形容词/感叹号/内心独白宣布；
- 连续高强度，读者疲劳；
- 情绪转折没有铺垫，读者无感；
- 该爽的地方不爽，该疼的地方不疼。

**更好的写法**：

- 用**选择/代价**制造情绪：他为了救她，放弃了什么？
- 用**具体细节**让读者自己感到，而不是告诉读者“很感人”；
- 张弛交替：高压后给一个短呼吸，再压上去；
- 高潮用**动作/决定**收，不要用总结句解释。

## 7. 人物声音 / 魅力

**问**：

- 人物想要什么？为什么现在？他的矛盾是什么？
- 他的选择是否暴露了他的价值底线？
- 他的声音是否可区分？他遮掩/攻击/亲密的方式是什么？
- 读者为什么会喜欢/好奇/心疼他？
- 反派/配角是否有自己的账本，而不是工具人？

**常见病症**：

- 人物只有功能，没有欲望/矛盾；
- 所有人说话一个腔调；
- 人物做作者需要的事，而不是他会做的事；
- 反派坏得没有逻辑/没有成本；
- 主角没有“让人想跟着看”的特质。

**更好的写法**：

- 给人物一个**具体、可失去的目标**；
- 用**压力选择**揭示人物真相：他在两难里选什么，比他说什么更重要；
- 给每个人一个**语言习惯/遮掩方式**；
- 给反派一个**自己的账本**：他为什么觉得自己对？
- 让主角有一个**记忆点**：一个动作、一个口头禅、一个物件、一个反常选择。

## 8. 幕 / 序列 craft

**问**：

- 这一幕/序列在卷/全书里做什么？开局、推进、转折、揭示、蓄势、收束？
- 有没有**幕级逆转/中点**？是什么改变了方向？
- 冲突是否**渐进复杂化**：目标更难、选择更少、代价更高？
- 高潮是否由主角的**选择**造成？有没有代价？
- 收束是否留下**不可逆变化**和**新问题**？
- 章功能分布是否合理：有没有空转章、重复章、该压不压/该展不展？

**常见病症**：

- 一幕下来，主角只是被事件搬运；
- 中段平，靠日常/对话撑；
- 高潮靠外力/降神，不是主角选择；
- 章与章功能重复，删掉一章也不影响；
- 幕末没有新方向，只是“下一件事”。

**更好的写法**：

- 先定**幕功能**，再排章功能；每章至少推进一个维度（目标/关系/信息/风险/情绪）；
- 用**约束式升级**：不是“敌人更强”，是“选择更少、代价更高”；
- 中点给一个**改变理解/方向**的逆转；
- 高潮让主角做**两难选择**，并承担代价；
- 幕末留**新问题/新方向**，不是总结。

## 9. “更好的写法”速查表

| 病症 | 技法 | 示例方向（不是代写） |
|---|---|---|
| 解释太多 | 解释→动作/物件 | 不写“他很愤怒”，写“他把茶杯捏裂了” |
| 情绪靠旁白 | 情绪→身体/选择 | 不写“她很害怕”，写“她第三次忘了自己要说什么” |
| 全知镜头 | POV 过滤 | 逃命时只看到出口、追兵、脚下的泥 |
| 信息倾倒 | 冲突中交付 | 让信息成为谈判筹码/威胁/代价 |
| 对白直给 | 答非所问/潜台词 | 她问“你信我吗”，他答“船要开了” |
| 人物声音雷同 | 词汇/句长/遮掩 | 一个用短句命令，一个用玩笑回避，一个沉默 |
| 场景无转折 | 价值翻转 | 安全→危险、信任→怀疑、希望→失望 |
| 动作堆砌 | 选择/代价 | 每次出手都让他失去一点什么 |
| 套话 | 具体细节 | 不写“空气凝固”，写“灯芯爆了一声，没人接话” |
| 比喻过多 | 一个准确比喻 | 只留一个能服务情绪的比喻 |
| 总结句 | 删掉，让动作说话 | 删“他终于明白了”，保留他放下的手 |
| 章末平收 | 具体期待 | 不是“欲知后事”，是一个具体问题/威胁/决定 |
| 人物无欲望 | 具体目标 | 不是“想变强”，是“想拿回母亲的遗物” |
| 反派工具人 | 自己的账本 | 他为什么觉得自己对？他怕失去什么？ |
| 描写无视角 | 谁在看/在意什么 | 情人眼里看到的是手，不是建筑全景 |
| 节奏平 | 长短句/段落变化 | 紧张短句，抒情放慢，但别空转 |
| 对话标签过多 | 动作替代 | 用“他把门关上”替代“他冷冷地说” |
| 入口太慢 | 从异常/冲突开始 | 第一段就让人物面对问题 |
| 出口拖尾 | 在决定点结束 | 他做出选择的那一句就收 |
| 高潮被解释 | 用选择/代价收 | 不解释主题，让他付出代价 |

## 10. 1–5 分锚点（写作技巧）

| 分数 | 含义 |
|---|---|
| 5 | 强：有效、具体、有记忆点；可作为同类写法参考 |
| 4 | 良：成立，有少量可改进 |
| 3 | 中：能读，但平/可预测/靠类型惯性 |
| 2 | 弱：明显失效，影响阅读体验 |
| 1 | 无/反效果：不存在，或起反作用 |

允许 0.5 分。**每个子分必须带正文锚点与一句理由；“我觉得”不算证据。**

## 11. 常见误判

- 把“我不喜欢”当“写得不好”；
- 把“类型套路”当缺陷（先问类型契约）；
- 把“慢/留白/碎碎念”当坏；
- 把“华丽”当“好文笔”；
- 把“信息多”当“有深度”；
- 把“主角冷血/爽”当人物失败（先问类型）；
- 把“逻辑不通”当主评（逻辑是可选备注，不是写作技巧）；
- 用评审团的风格覆盖作者的声音。
