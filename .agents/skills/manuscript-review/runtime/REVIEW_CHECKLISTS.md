# 写作技巧检查清单

> 只评“好不好看、怎么写更好”。**不评设定/逻辑/时间线一致性。**
> 每条都要回到正文证据；没有证据的直觉只标“观察”。

## 0. 通用层

### 0.1 单位与功能

- 这是正章、序章/引子、间章、番外中的哪一种？POV 角色是不是全书主角？
- 这一幕/序列在卷/全书里承担什么？开局、推进、转折、揭示、蓄势、收束？
- 删掉这一幕/这一章，后文会缺什么？如果什么都不缺，功能可能不成立。
- 本章/本幕承诺了什么（问题、情绪、目标、悬念）？结尾给了继续读的理由吗？

### 0.2 读者体验

- 这一章/这一幕想让读者感受什么？期待、紧张、愤怒、爽、心疼、好奇？
- 有没有让读者出戏的地方（不是逻辑错，而是“读不下去/不想看”）？
- 信息密度是否可承受？有没有连续大段解释/内心独白？
- 情绪曲线是否有起有落？有没有连续的平/连续的吼？
- 读完后，读者最想知道的下一件事是什么？

### 0.3 视角与叙述

- 这一场/这一章的 POV 是谁？有没有无标记跳视角？
- 叙述距离是否稳定？有没有突然从贴身限知跳到全知解释？
- 读者是否通过 POV 的感官/判断进入场景？
- 叙述者的语气是否稳定？有没有突然变成作者评论？

## 1. 场景

- 这一场谁想要什么？阻力是什么？结束时什么变了？
- 入口是否够快？读者是否知道“我们在哪、为什么在这”？
- beat 是否有推进：试探→拒绝→威胁→让步→反转？
- 场景是否在“发生”事情，还是只在“交流信息”？
- 结尾是否落在决定/转折/钩子上，而不是拖尾？
- 有没有价值翻转（安全→危险、信任→怀疑、希望→失望）？
- 场景的压缩/展开是否合理？哪里该快、哪里该慢？

## 2. 对白

- 每句对白在做什么：请求、拒绝、试探、威胁、安抚、回避、挑衅、承认、转移？
- 有没有“说了很多但局势没变”？
- 潜台词是否有效：人物说的和要的是否有落差？
- 人物声音是否可区分：词汇、句长、逻辑、遮掩方式？
- 信息交付是否自然：有没有 As-you-know、解释倾倒、重复交付？
- 对话标签是否过多/过花？动作是否替代了标签？
- 沉默、打断、答非所问是否被有效使用？

## 3. 描写与文字

- 这段描写是谁在看？他此刻在意什么？情绪如何过滤环境？
- 感官细节是否具体、节制、服务场景？
- 比喻是否准确、新鲜、服务情绪？有没有混合比喻/过度比喻？
- 是否在用形容词代替动作？动词是否具体？
- 有没有套话、AI 味、同构比喻、四字成语堆砌？
- 描写是否服务场景/情绪/信息，还是为了画面感而画面感？
- 段落长度是否适合目标平台（手机阅读/连载）？

## 4. 节奏与可读性

- 句子长短是否有变化？紧张场景是否用短句/断句？
- 有没有连续大段说明/内心独白打断动作？
- 该快的地方快了吗？该慢的地方慢了吗？
- 场景/章节的压缩/展开是否合理？
- 章末是否给出具体期待（问题/决定/威胁），而不是空钩？
- 读起来是否顺畅？有没有需要回看才能理解的句子？

## 5. 人物与情感

- 人物想要什么？为什么现在？触发是什么？
- 关键选择是人物做的，还是作者需要他做？
- 人物的矛盾是什么？压力下暴露了什么？
- 人物声音是否可区分？他遮掩/攻击/亲密的方式是什么？
- 读者为什么会喜欢/好奇/心疼他？他有没有记忆点？
- 关系是否有张力、方向性、变化？还是所有人围着主角转？
- 情感是否由动作/选择/代价支撑，而不是旁白宣布？
- 人物弧/关系变化是否可信？有没有事件→解释→内部效果→发展结果？

## 6. 幕 / 序列

- 这一幕/序列在卷/全书里做什么？功能完成了吗？
- 有没有幕级逆转/中点？是什么改变了方向？
- 冲突是否渐进复杂化：目标更难、选择更少、代价更高？
- 高潮是否由主角的选择造成？有没有代价？
- 收束是否留下不可逆变化/新问题？
- 章功能分布是否合理？有没有空转章、重复章、该压不压/该展不展？
- 中段是否平？靠什么撑住读者？
- 幕末钩子是否具体？

## 7. 类型 / 读者

- 是否履行类型核心期待？是否给出惊喜？
- 追读动力（好奇/关心/期待）如何？
- 情绪曲线是否有效？爽点/痛点是否到位？
- 有没有为了“高级”而牺牲可读性？有没有为了“爽”而牺牲人物？
- 目标平台/读者是谁？这个写法对他们有效吗？

## 8. 写作技巧速查

| 病症 | 技法 |
|---|---|
| 解释太多 | 解释→动作/物件 |
| 情绪靠旁白 | 情绪→身体/选择 |
| 全知镜头 | POV 过滤 |
| 信息倾倒 | 冲突中交付 |
| 对白直给 | 答非所问/潜台词 |
| 人物声音雷同 | 词汇/句长/遮掩方式 |
| 场景无转折 | 价值翻转 |
| 动作堆砌 | 选择/代价 |
| 套话 | 具体细节 |
| 比喻过多 | 一个准确比喻 |
| 总结句 | 删掉，让动作说话 |
| 章末平收 | 具体期待 |
| 人物无欲望 | 具体目标 |
| 反派工具人 | 自己的账本 |
| 描写无视角 | 谁在看/在意什么 |
| 节奏平 | 长短句/段落变化 |
| 对话标签过多 | 动作替代 |
| 入口太慢 | 从异常/冲突开始 |
| 出口拖尾 | 在决定点结束 |
| 高潮被解释 | 用选择/代价收 |

## 9. 常见误判

- 把“我不喜欢”当“写得不好”。
- 把“类型套路”当缺陷（先问类型契约）。
- 把“慢/留白/碎碎念”当坏。
- 把“华丽”当“好文笔”。
- 把“信息多”当“有深度”。
- 把“主角冷血/爽”当人物失败（先问类型）。
- 把“逻辑不通”当写作问题（逻辑不在本清单）。
- 用评审团的风格覆盖作者的声音。
