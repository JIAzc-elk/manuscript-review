# 故事设计透镜（Story / Dialogue / Character）

> **目的**：在“逻辑是否自洽”之外，回答“是否好看”。
>
> 这一层看的是故事设计的承重件：激励事件、求索、鸿沟、场景价值转折、幕/序列逆转、不归点、危机/高潮、人物矛盾、人物弧、类型契约。
>
> **理论是透镜，不是法律。** 不要求每一章都具备全部元素；先问“这一章的功能/类型是否需要它”，再判断“它做得怎么样”。不要用“缺少某个元素”自动判错。

## 0. 使用方法

- **Phase 1**：结构、人物、场景三个角色各答自己领域的 craft 问题，给 1–5 子分。
- **Phase 2**：魔鬼检查子分是否与证据匹配（是否虚高/虚低），拆解员核对引文。
- **Phase 3**：主持校准，填入 `Craft Scorecard`，得出“故事设计分”（1–10）。
- **报告**：单独列“故事设计评分”表，并给一句“是否好看”的判断；它与五维总分并列，不互相替代。

**1–5 子分锚点**：

| 分数 | 含义 |
|---|---|
| 5 | 强：清晰、有效、有惊喜/深度；可作为同类范例 |
| 4 | 良：成立，有少量可改进 |
| 3 | 中：基本成立，但效果一般/可预测 |
| 2 | 弱：缺失或失效，明显影响阅读 |
| 1 | 无/反效果：不存在，或起了反作用 |

允许 0.5 分。**子分必须带正文/素材锚点与一句理由；没有证据的子分不成立。**

## 1. 激励事件（Inciting Incident）

**问题**：是否打破主角的平衡？是否迫使他做出反应/选择？时机是否合适？是否与主线求索相连？

**强信号**：

- 主角的日常被不可逆地改变；
- 他必须行动，不能原地不动；
- 读者能感到“故事从这里开始”；
- 事件与主角的欲望/恐惧/旧伤有直接关系。

**弱信号**：

- 事件只是“发生在他身上”，他没有选择；
- 事件与主线欲望无关，只是热闹；
- 太晚（读者已经失去耐心）或太早（读者还不知道它为何重要）；
- 靠旁白宣布“这是改变命运的一刻”。

**评分锚点**：

- 5：不可逆、与主角欲望咬合、迫使他选择，且时机精准；
- 4：成立，略有延迟或关联不够紧；
- 3：事件发生了，但主角只是被动承受；
- 2：事件与主线脱节，或靠巧合；
- 1：没有激励事件，或它被写成背景说明。

**常见误判**：把“大场面”当激励事件；把“背景事件”当激励事件；要求第一章就完整展开。

## 2. 求索 / 故事脊椎（Quest / Spine）

**问题**：主角想要什么（意识欲望/潜在欲望）？阻力是什么？求索是否贯穿？有没有回头路？

**强信号**：

- 一个可追踪的目标（人、物、真相、复仇、逃生、爱）；
- 每个场景都在推进/阻碍它；
- 读者能问“他下一步会怎么做”；
- 意识欲望与潜在欲望有张力（他以为自己要 A，其实要 B）。

**弱信号**：

- 主角只是被事件搬运；
- 目标模糊、随时可换；
- 支线淹没主线；
- 只有“活下去”这种太泛的求索，没有具体对象。

**评分锚点**：

- 5：目标具体、阻力明确、贯穿全章、有意识/潜在欲望张力；
- 4：目标清楚，阻力稍弱或贯穿性不足；
- 3：有目标，但只是被动反应；
- 2：目标模糊/可替换，读者不知道他要什么；
- 1：没有求索，只有事件清单。

**常见误判**：把“作者想写什么”当主角欲望；把“生存”当唯一求索；要求每章都完成求索。

## 3. 鸿沟（Gap）

**问题**：角色期待什么？实际结果是什么？鸿沟是否迫使他采取新行动？是否升级？

**强信号**：

- 每个场景有“期待 → 结果 → 鸿沟 → 新行动”；
- 鸿沟改变风险、关系、信息或目标；
- 角色因鸿沟调整策略，而不是重复同一动作；
- 鸿沟层层加码，直到危机。

**弱信号**：

- 计划顺利实现，没有意外；
- 反转随机，角色不调整；
- 鸿沟只靠“新敌人出现”制造；
- 角色知道得太多，期待没有落空。

**评分锚点**：

- 5：鸿沟驱动行动升级，改变局势，且与人物欲望咬合；
- 4：有鸿沟，但升级不够或只在一两场生效；
- 3：有意外，但角色反应机械；
- 2：鸿沟靠巧合/新信息硬造；
- 1：没有鸿沟，事件按计划走。

**常见误判**：把“意外”当鸿沟；把“信息揭示”当鸿沟；要求每场都有大鸿沟。

## 4. 场景价值转折（Scene Value Turn）

**问题**：场景开始/结束的价值电荷（正/负）是否变化？谁赢谁输？什么价值被翻转？

**强信号**：

- 场景结束时，人物/关系/信息/局势与开始时不同；
- 价值从 + 到 - 或 - 到 +；
- 转折由人物行动造成，不是旁白宣布；
- 场景的“入口/出口”清楚。

**弱信号**：

- 原地踏步；
- 只有信息交换，没有价值变化；
- 情绪重复，局势不变；
- 场景结束在“然后呢”，而不是“所以呢”。

**评分锚点**：

- 5：价值翻转清楚、由人物选择造成、服务主线；
- 4：有转折，但幅度/因果稍弱；
- 3：有变化，但只是情绪/信息；
- 2：几乎没有变化；
- 1：场景可删，删除后无损失。

**常见误判**：把“有冲突”当“有转折”；把“情绪变化”当“价值变化”；要求每场都大起大落。

## 5. 序列 / 幕逆转（Sequence / Act Turn）

**问题**：这一幕/序列结束时，什么重大逆转发生？目标/风险/关系/信息是否改变？是否把故事推向新方向？

**强信号**：

- 幕末不可逆；
- 主角的选择/代价改变后续；
- 观众重新理解局势/人物；
- 逆转由前面的铺垫支撑，不是天降。

**弱信号**：

- 幕末只是“下一件事”；
- 逆转靠巧合/新人物/新设定；
- 没有价值翻转，只是换个场景；
- 幕的划分靠字数，不靠功能。

**评分锚点**：

- 5：重大逆转、不可逆、改变后续方向、有铺垫；
- 4：有逆转，但影响/铺垫稍弱；
- 3：有变化，但只是推进，不是逆转；
- 2：逆转靠巧合/降神；
- 1：没有幕/序列逆转，事件平铺。

**常见误判**：用“章节字数”划分幕；要求每章都有幕逆转；把“反转”当“逆转”（反转是信息，逆转是价值/方向）。

## 6. 不归点（Point of No Return）

**问题**：主角何时跨过不可逆的门？代价是什么？是否太早/太晚？之后还能回头吗？

**强信号**：

- 一个明确的选择/行动，切断退路；
- 代价可见（关系、身份、道德、资源）；
- 后续必须面对后果；
- 不归点与求索/主题咬合。

**弱信号**：

- 没有不归点，随时可以退出；
- 不归点靠外部强迫，不是主角选择；
- 代价不可见/可撤销；
- 太早（读者还没在乎）或太晚（拖到最后）。

**评分锚点**：

- 5：选择明确、代价可见、不可逆、与主题咬合；
- 4：有不归点，但代价/时机稍弱；
- 3：有“决定”，但还能回头；
- 2：不归点靠外力，主角没有选择；
- 1：没有不归点。

**常见误判**：把“受伤/失败”当不归点；把“决定”当不归点但没有代价；要求每章都有不归点。

## 7. 危机 / 高潮 / 结局（Crisis / Climax / Resolution）

**问题**：最大压力下的选择是什么？是否由主角做出？是否兑现主题/承诺？高潮后状态是否不可逆？结局是否给余波/新平衡？

**强信号**：

- 危机是两难，不是单纯打斗；
- 高潮是选择的结果，不是外力/降神；
- 价值不可逆，故事状态改变；
- 结局有余波/新问题/新平衡。

**弱信号**：

- 高潮靠外力/新人物/新能力；
- 选择没有代价；
- 结局只是停笔；
- 高潮与前面的铺垫无关。

**评分锚点**：

- 5：两难选择、由主角做出、兑现主题、状态不可逆、有余波；
- 4：高潮成立，但选择/代价稍弱；
- 3：有高潮，但靠场面/外力；
- 2：高潮与铺垫脱节；
- 1：没有危机/高潮，或它被解释掉。

**常见误判**：把“最大场面”当高潮；把“解释”当结局；要求每章都有完整高潮。

## 8. 人物矛盾（Character Contradiction）

**问题**：人物内部/个人/超个人冲突是什么？是否有生产性矛盾（爱恨、忠诚与自利、依赖与反抗）？压力下暴露了什么？

**强信号**：

- 人物在压力下做出揭示真相的选择；
- 矛盾不被强行统一；
- 对手有等价逻辑/资源/主动性；
- 人物的“想要”与“需要”有张力。

**弱信号**：

- 人物只有一个情绪/目标；
- 反派工具化/降智；
- 矛盾靠台词说明，不靠行动；
- 人物没有真正的两难。

**评分锚点**：

- 5：多重矛盾、压力选择揭示真相、对手有逻辑；
- 4：有矛盾，但层次/压力稍弱；
- 3：有冲突，但比较单一；
- 2：矛盾靠台词/功能化；
- 1：没有人物矛盾。

**常见误判**：把“人物吵架”当矛盾；把“人设矛盾”当缺陷；要求人物一直犹豫。

## 9. 人物弧（Character Arc）

**问题**：起点/终点价值是什么？变化是否有事件→解释→内部效果→发展结果？速率可信吗？

**强信号**：

- 变化由选择/代价推动；
- 有反复/阻力/旧习惯；
- 结尾价值与开头不同；
- 变化留下后果。

**弱信号**：

- 突然成长/黑化；
- 没有事件支撑；
- 变化不可逆得太快；
- 变化只靠旁白总结。

**评分锚点**：

- 5：弧光由选择/代价推动、速率可信、有反复、留下后果；
- 4：有变化，但支撑/速率稍弱；
- 3：有变化，但比较表面；
- 2：突然变化/靠旁白；
- 1：没有弧光，或反复横跳。

**常见误判**：把“学会一个道理”当弧光；要求每章都成长；把“不变”当缺陷。

## 10. 类型契约 / 读者体验（Genre / Reader Experience）

**问题**：是否履行类型核心期待？是否给出惊喜？追读动力（好奇/关心/期待）如何？情绪曲线是否有效？

**强信号**：

- 类型读者能获得预期爽点/痛点；
- 同时有新鲜感/反转；
- 章末有具体期待；
- 情绪曲线有起有落，不是平线。

**弱信号**：

- 套路化到可预测；
- 反套路到违背类型承诺；
- 情绪平/靠吼；
- 章末没有问题。

**评分锚点**：

- 5：类型期待+惊喜、追读动力强、情绪曲线有效；
- 4：类型成立，惊喜/情绪稍弱；
- 3：合格但可预测；
- 2：类型失约/情绪平；
- 1：读者没有继续读的理由。

**常见误判**：用文学标准评类型文；把“爽”当低俗；把“慢”当高级。

**故事设计分（Craft Index）** = 10 项平均 × 2（1–10）。允许 0.5 刻度。

它不是五维总分的替代，而是“是否好看”的独立诊断：

- **Craft Index 明显低于总分**：逻辑/文字尚可，但故事设计是短板；
- **Craft Index 明显高于总分**：故事有想法，但执行/逻辑/文字拖后腿；
- **两者接近**：发展均衡。

## 12. 与五维评分的关系

- **故事设计与结构**（ST）应重点参考 1、2、3、5、6、7 的子分；
- **人物与矛盾**（CH）应重点参考 8、9 的子分，并结合关系/知识边界 findings；
- **场景执行与对白**（SD）应重点参考 4 的子分，并结合对白/信息交付/调度 findings；
- **设定/语言**（WD/PR）不直接进 Craft Scorecard，但在总分中保留权重。

允许维度分与子分不完全相等；如果差距大，报告必须解释“为什么整体判断高于/低于某一项”。

## 13. 序章 / 引子特例

如果这一章是**序章、引子、楔子、前传**，或 POV 角色不是全书主角，评分标准要换，不能拿“主角第一幕”的尺子量它。

**先问四个问题**：

1. **契约**：读者是否知道这是序章/引子？标题、卷首、作者说明、框架叙事有没有给出信号？如果标成“第1章”却在中途换主角，读者可能觉得被骗。
2. **功能**：这一章是否完成了“建立缺失/悲剧/世界规则/悬念，并把故事交给真正主角”？
3. **人物**：序章 POV 角色的“弧”可以是**揭示**而不是**改变**——他不必成长，但必须在压力下暴露真相；他的选择要能解释后文的债。
4. **交接**：章末是否把“下一步”交给真正主角/主线？读者是否知道“故事还没完，但视角要换了”？

**评分调整**：

- **求索**：不要求序章 POV 拥有完整主线求索；看他是否建立了“缺失/债/问题”，并把求索交给真正主角。做到即可给 4–5。
- **人物弧**：不要求序章 POV 完成成长弧；看“揭示”是否成立、选择是否有代价、是否留下后文要还的债。做到即可给 3.5–5。
- **类型契约**：序章有“读者愿意跟着换主角”的额外风险；如果标签/框架没做好，这一项要扣。
- **不归点/危机/高潮**：序章的 POV 可以死亡/退场；关键是这个退场是否成为主线的“激励事件”或“债源”。

**常见误判**：

- 把序章 POV 当全书主角，要求他完成成长弧 → 误判“人物弧低”。
- 把序章的“没有下一步”当缺陷 → 忽略它可能是在交接。
- 把“第1章”当“序章” → 忽略读者契约风险。
- 把序章的悲剧当“虐主” → 忽略它可能是主线的债源。

## 14. 写作纪律

- 不要求每章都具备全部 10 项；先判断章节功能/类型，再判断“该有的有没有做好”。
- 不把“缺少激励事件”自动判 P0；先问这一章是不是“激励事件章”。
- 不把“人物没有成长”当缺陷；有些章节的功能是展示/蓄势。
- 不把“爽”当低俗，也不把“慢”当高级。
- 子分必须可被反驳：给出证据、机制、适用条件。
- 理论是透镜，不是法律；作者明确反类型/反套路时，按作者意图调整。
